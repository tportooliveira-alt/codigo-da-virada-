# 💕 Wallpaper Romântico para Fernanda

Wallpaper bonito e elegante com mensagens de amor criado especialmente para você deixar para Fernanda.

---

## 📱 Como usar

### Opção 1: Arquivo HTML (Rápido)
1. Abra o arquivo `wallpaper-fernanda.html` em qualquer navegador
2. Deixe em tela cheia (pressione F11)
3. Aproveite o visual romântico!

**Para usar como wallpaper do Windows:**
- Clique direito na imagem → "Definir como wallpaper"
- Ou tire screenshot (Print) → Cole no Paint → Salve como .jpg → Defina como wallpaper

### Opção 2: Design no Canva (Customizável)
📍 **Link:** https://www.canva.com/d/idXj4t2f-Qyq5Ta

Aqui você pode:
- Editar os textos
- Mudar as cores
- Adicionar fotos
- Exportar em PNG, JPG ou PDF
- Imprimir em alta qualidade
