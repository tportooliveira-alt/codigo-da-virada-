# 💕 Como Colocar o Wallpaper Romântico

Dois jeitos fáceis para definir o wallpaper como plano de fundo do seu PC!

---

## 🚀 **JEITO 1: Automático (Recomendado!)**

### Windows:

1. **Abra a pasta do projeto** no seu PC
2. **Clique com botão direito** em `set-wallpaper-fernanda.bat`
3. **Escolha: "Executar como Administrador"**
4. **Pronto!** ✨ O wallpaper já está setado!

**O script vai:**
- ✅ Criar a imagem automaticamente
- ✅ Salvar na pasta correta do Windows
- ✅ Definir como plano de fundo
- ✅ Tudo em menos de 30 segundos!

---

## 📱 **JEITO 2: Manual**

Se o script não funcionar, faça assim:

1. Abra `wallpaper-fernanda.html` no navegador
2. Deixe em tela cheia (F11)
3. Tire screenshot (Print)
4. Abra o Paint
5. Cole (Ctrl+V)
6. Salve como `wallpaper.jpg` na pasta `C:\Users\SEUUSUARIO\Pictures\`
7. Clique direito na imagem → **"Definir como plano de fundo"**

## ⚡ **Se tiver dúvida:**

- **Não funciona o .bat?** Tente clicar com botão direito e escolher "Executar como Administrador"
- **Antivírus bloqueou?** É normal, só clique em "Permitir"
- **Quer customizar?** Abra o arquivo HTML e edite os textos
- **Quer em alta resolução?** Use o Canva: https://www.canva.com/d/idXj4t2f-Qyq5Ta
